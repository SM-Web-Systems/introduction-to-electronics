# Introduction to Electronics — Module 3: Essential Components
Target audience: complete beginners (~16 years old) preparing to build with Arduino.
Learning objectives:
- Resistors: types, colour codes, tolerances, and current limiting.
- Capacitors: function, ratings, and polarisation.
- Diodes and LEDs: behaviour and uses.
- Transistors (NPN/PNP) as basic switches.
- Inductors and basic magnetism.
