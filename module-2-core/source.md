# Introduction to Electronics — Module 2: Core Concepts
Target audience: complete beginners (~16 years old) preparing to build with Arduino.
Learning objectives:
- Voltage, current and resistance; Ohm's Law (V = I x R) and how to apply it.
- Electrical power and energy calculations (P = V x I).
- The difference between AC and DC and where each is used.
- How series and parallel circuits behave (voltage, current, resistance combination).
