# Electronics Quiz

## Question 1

- [ ] It causes the circuit to use the least amount of power possible.
- [x] It creates a low-resistance path that leads to excessive current flow and heat.

**Hint:** Think about how electricity behaves when it encounters a path with almost no resistance.
